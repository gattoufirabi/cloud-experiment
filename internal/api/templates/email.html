Send with the API

curl -X POST -H "Authorization: Bearer $EMAIL_TOKEN" -H 'Content-Type: application/json' $EMAIL_API_URL \
  -d '{"from": "Shop <hello@{{if .Verified}}{{index .Verified 0}}{{else}}example.com{{end}}>", "to": ["buyer@example.org"],
       "subject": "Your order", "text": "Thanks!", "html": "<p>Thanks!</p>"}'

Answers 202 with the message id; GET /api/v1/email/messages/ID gives its status and each recipient's result. Up to 50 recipients; text and HTML up to 256 KB.

Attachments

Add "attachments": a list of files with a name, a media type and the bytes in base64 (up to 20 files, 10 MB per message in total; programs and scripts such as .exe or .js are refused).

"attachments": [{"filename": "invoice-1042.pdf", "content_type": "application/pdf", "content": "JVBERi0xLjcK..."}]
