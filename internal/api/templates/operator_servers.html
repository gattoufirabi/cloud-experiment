Add a server

A worker server runs the agent and the projects placed on it; the primary keeps the console, the database and the proxy. Servers talk over WireGuard.

  1. Connect the new server to the primary with WireGuard and note both private addresses (for example 10.8.0.1 and 10.8.0.2).
  2. On the primary, set CONTROL_PLANE_ADDRESS in deploy/.env to its private address and run docker compose -f compose.prod.yml up -d.
  3. On the primary, create the join bundle (it holds secrets, copy it over SSH only): 
    sudo bash /opt/platform/host/node-bundle.sh --node-id node-2 --node-address 10.8.0.2 --cluster default
  4. On the new server, with the code in /opt/platform: 
    sudo bash host/deploy.sh --worker --bundle <bundle>
  5. It appears above within a minute; new projects go to the online server with the most free memory.
