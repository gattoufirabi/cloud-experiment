Grafana and Prometheus

Your metrics (CPU, memory and network of every instance, plus your applications' own metrics when a service sets a Metrics path) are available through a Prometheus-compatible API, limited to your organization.

# Prometheus server URL (in Grafana: Prometheus data source, header Authorization: Bearer <API token>)
{{.BaseURL}}/api/v1/prometheus

curl -H "Authorization: Bearer $TOKEN" "{{.BaseURL}}/api/v1/prometheus/api/v1/query?query=sum(rate(platform_container_cpu_seconds_total[5m]))"
{{if and (roleAtLeast .Org.Role "developer") .Projects}}

A grafana service with the data source and a services dashboard already set up, its data kept in a persistent folder. It counts as one service (250 millicores, 256 MB).
