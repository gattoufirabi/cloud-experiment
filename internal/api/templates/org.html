Deploy from CI

Use the REST API or the platformctl tool with a token. A token acts within this organization only, with the role you give it.

export PLATFORM_URL={{.BaseURL}}
export PLATFORM_TOKEN=pla_…
platformctl deploy <project>/<service> --image <image> --wait

# or with curl
curl -X POST -H "Authorization: Bearer $PLATFORM_TOKEN"   -d '{"image": "<image>"}' $PLATFORM_URL/api/v1/projects/<project>/services/<service>/deploy
