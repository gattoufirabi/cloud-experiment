Guide: builds from git ↗

Build from git

The platform clones the branch and builds it in an isolated sandbox: with its Dockerfile if there is one, otherwise with Railpack, which detects Node, Python, Go, PHP, Ruby, Java, Rust, Elixir and static sites. The image is stored in your registry space, scanned and, if you choose, deployed with this service's settings.
